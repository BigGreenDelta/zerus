# Task Tools over MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agents in Claude Code and Codex sessions that Zerus starts get the `zerus` MCP server: `hgs mcp` serves the `task_*` tools over the project's local replica, acting as the verified session that runs it. Zerus allows the tools in advance, and task prompts name them.

**Architecture:**
- `src/task_mcp.rs` is a stdio JSON-RPC server. Each tool call is translated into the `hgs task` command it equals, so routing to another computer, the project settings and every check stay in one place.
- To make that possible, `src/tasks.rs` runs those commands through `tasks::execute`, which returns their JSON instead of printing it. `execute` takes the text and the verified agent from the server.
- `lifecycle::run` attaches the server to each start of a Claude Code or Codex session. It adds the flags only to the spawned argv and records `"zerus_mcp": true` in that run's record.
- `tasks::send` and `cancel` read that flag to name `zerus.task_*` in the prompts.

**Tech Stack:** Rust 1.99.1 (`hgs`, serde_json, toml_edit, chrono), `zerus-replica`, Python `unittest` end-to-end tests through the real CLI, and native contract tests with the real Claude Code and Codex against localhost fixtures.

**Spec:**
- `docs/superpowers/specs/2026-10-13-project-task-queue-design.md`: the sections "Agent interface", "MCP server `zerus`", "Tool responses" and "Server instructions".
- `docs/superpowers/specs/2026-10-18-task-replication-loro-design.md`: phase 4, and "Actions with side effects".

- `crates/replica` remains the only code that imports Loro. `src/task_mcp.rs` uses `zerus_replica` types only.
- Repository text is in English. Fixtures use invented names only: project `orchard` (`project-1`), project `team/web` (`project-2`), and sessions `claude/orchard/api`, `codex/task-test` and `codex/remote`.
- The server attaches "on the command line of that start only (Claude Code `--mcp-config`, Codex `-c mcp_servers.zerus.…`); the agent's own configuration and saved resume commands never contain it."
- "The server inherits the session's `HGS_SESSION` and `HGS_RUN_ID` from the agent (Codex is told to pass them on by name) and checks on every call that this run of the session is live on this computer; its project is the catalog project of that session."
- "A server that cannot verify its session, or whose session belongs to no project, refuses every tool with the reason."
- "The same command line allows the zerus tools, so the agent never asks the person before calling them": Claude Code gets `--allowedTools mcp__zerus`; Codex gets `default_tools_approval_mode = "approve"`.
- "A session started by an older Zerus gets the server at its next resume; until then its task prompts name the `hgs task` commands."

  - The own-task cancel refusal.
  - `"Filed orchard/T-51 in To do, position 5, for orchard/api."`
- Every stdout line of `hgs mcp` is a JSON-RPC message. Logs go to stderr.
- Commits:
  - No co-author lines.
  - Stage only this plan's files (`git add <paths>`). Other sessions edit this checkout.
  - Never push, merge, rebase or switch branches; work stays on `task-tracker`.
- Every tmux kill names its socket (`-S`). The existing fixtures already do this.

## Review Focus

1. **A session renamed after it started.** Tools act, and file tasks, under the session's current name, because `caller_record` follows renames. Pinned in Task 1 by `test_a_renamed_session_acts_under_its_current_name`.
2. **A session moved to another project while its server runs.** The next call works on the new project, because the project is looked up on every call. Pinned in Task 1 by the same test.
3. **A prompt given after `--` on the command line.** The flags land once, before `--`, on start, resume and fork, and the prompt stays prompt text. Pinned in Task 4 by `test_the_tools_come_before_a_prompt_and_only_once`.
4. **A Codex agent whose environment lacks some forwarded variables** (no `SSH_AUTH_SOCK`, no `TMUX`). Codex still starts the server, with the variables that exist. Pinned in Task 6 by the native Codex test, which leaves most of the list unset.
5. **Text arguments that are not strings or exceed 64 KiB.** The tool refuses with the reason, and the server keeps answering the next call. Pinned in Task 2 by `test_bad_arguments_are_refused_and_the_server_goes_on`.

```python
def write_caller(state, env, name, run_id, **fields):
    """A live run of `name` whose agent is this test process."""
    start = subprocess.check_output(["ps", "-p", str(os.getpid()), "-o", "lstart="],
                                    env=dict(env, LC_ALL="C", TZ="UTC"), text=True).strip()
    record = dict(version=1, name=name, agent="claude", run_id=run_id, conversation_id=str(uuid.uuid4()),
                  pid=os.getpid(), process_start=start, activity="busy", phase="input",
                  active_tools={}, subagents={}, created=time.time())
    record.update(fields)
    path = state / (hashlib.sha256(name.encode()).hexdigest() + ".json")
    path.write_text(json.dumps(record))
    return path


def swarm(env, *args, data=None):
    result = subprocess.run([str(HGS), "swarm", *args], input=json.dumps(data) if data is not None else None,
                            env=env, text=True, capture_output=True, timeout=30)
    assert result.returncode == 0, result.stderr
    return json.loads(result.stdout)


def join(env, project_id, name):
    """Moves this computer's session `name` into the catalog project `project_id`."""
    node = swarm(env, "export")["node_id"]
    before = swarm(env, "get")
    desired = copy.deepcopy(before["organization"])
    for project in desired["projects"]:
        project["sessions"] = [s for s in project.get("sessions", []) if s.split("\n", 1)[-1] != name]
        if project["id"] == project_id:
            project["sessions"].append(node + "\n" + name)
    swarm(env, "apply", data=dict(base=before["organization"], desired=desired, versions=before["versions"]))


def serve(env, *calls, session=CALLER, run_id=RUN):
    """`hgs mcp`'s answers to initialize and then to each (tool, arguments) call."""
    lines = [dict(jsonrpc="2.0", id=0, method="initialize",
                  params=dict(protocolVersion="2025-06-18", capabilities={}, clientInfo=dict(name="fixture", version="1"))),
             dict(jsonrpc="2.0", method="notifications/initialized")]
    lines += [dict(jsonrpc="2.0", id=n, method="tools/call", params=dict(name=name, arguments=arguments))
              for n, (name, arguments) in enumerate(calls, 1)]
    env = dict(env)
    if session:
        env.update(HGS_SESSION=session, HGS_RUN_ID=run_id)
    result = subprocess.run([str(HGS), "mcp"], input="".join(json.dumps(line) + "\n" for line in lines),
                            env=env, text=True, capture_output=True, timeout=120)
    assert result.returncode == 0, result.stderr
    # Every stdout line is a protocol message.
    answers = [json.loads(line) for line in result.stdout.splitlines()]
    assert [a.get("id") for a in answers] == list(range(len(calls) + 1)), result.stdout
    return answers


def answer_text(answer):
    """The text of a tool result, and whether it is an error."""
    result = answer["result"]
    return result["content"][0]["text"], result["isError"]
```

```rust
/// The live catalog project (ID, name) that this computer's session `name`

pub(crate) fn session_project(config: &Config, name: &str) -> Result<Option<(String, String)>> {
    let snapshot = LockedStore::load(config)?.snapshot(config);
    // The snapshot names this computer's sessions "<this host>\n<session>".

}
```

```rust
//! stdio MCP server (JSON-RPC 2.0, one message per line; stdout carries
//! protocol messages only). Zerus attaches it to the Claude Code and Codex
//! sessions it starts; every call verifies that session again, since it may be
//! renamed or moved to another project meanwhile. Each tool runs the `hgs task`
//! command it equals. See "MCP server `zerus`" in

/// The session that runs this server, verified, and the catalog project it belongs to.
struct Caller {
    session: SessionKey,
    project: (String, String),
}

fn caller(config: &Config) -> Result<Caller> {
    let record = crate::state::session_graph::caller_record().ok_or_else(|| {
        fail("No live Zerus session runs this MCP server; Zerus attaches it to the Claude Code and Codex sessions it starts.")
    })?;
    let name = record["name"].as_str().unwrap_or_default().to_owned();
    let machine = crate::swarm::local_node_id(config).map_err(fail)?;
    let project = crate::swarm::session_project(config, &name).map_err(fail)?.ok_or_else(|| {
        fail(format!("{name} belongs to no project, and tasks belong to projects. Move the session into a project in Zerus to use them."))
    })?;
    Ok(Caller { session: SessionKey { machine, session: name }, project })
}

/// The task of the caller's project that `reference` names, as `hgs task` takes it.
fn task_id(caller: &Caller, reference: &str) -> Result<String> {
    match reference.rsplit_once('/') {
        None => Ok(reference.to_owned()),
        Some((project, task)) if project == caller.project.0 || project == caller.project.1 => Ok(task.to_owned()),
        Some(_) => Err(fail(format!(
            "{reference} is not a task of {}; this session works only with the tasks of its project.",
            caller.project.1
        ))),
    }
}

/// One tool call for the verified caller; the answer says what happened.
fn tool(config: &Config, caller: &Caller, name: &str, arguments: &Value) -> Result<String> {
    let string = |key: &str| -> Result<Option<String>> {
        match &arguments[key] {
            Value::Null => Ok(None),
            Value::String(value) => Ok(Some(value.clone())),
            _ => Err(fail(format!("{key} must be a string"))),
        }
    };
    let required = |key: &str| -> Result<String> { string(key)?.ok_or_else(|| fail(format!("{name} needs {key}"))) };
    let run = |args: Vec<String>, text: Option<String>| {
        tasks::execute(config, &args, &Input { text, agent: Some(caller.session.clone()) })
    };
    let project = caller.project.0.clone();
    match name {
        "task_list" => {
            let mut args = vec!["list".to_owned(), "--project".into(), project];
            if let Some(stage) = string("state")? {
                args.extend(["--stage".into(), stage]);
            }
            Ok(run(args, None)?.to_string())
        }
        "task_get" => {
            let id = task_id(caller, &required("ref")?)?;
            Ok(run(vec!["get".into(), id, "--project".into(), project], None)?.to_string())
        }
        _ => Err(fail(format!("unknown tool {name}"))),
    }
}

fn error(id: &Value, code: i64, message: &str) -> Value {
    json!({"jsonrpc": "2.0", "id": id, "error": {"code": code, "message": message}})
}

fn tool_result(outcome: Result<String>) -> Value {
    let (text, is_error) = match outcome {
        Ok(text) => (text, false),
        Err(error) => (error.message, true),
    };
    json!({"content": [{"type": "text", "text": text}], "isError": is_error})
}

/// The answer to one parsed message, or `None` for a notification.
fn handle(call: &dyn Fn(&str, &Value) -> Result<String>, message: &Value) -> Option<Value> {
    let Some(object) = message.as_object() else {
        return Some(error(&Value::Null, -32600, "a message must be a JSON object"));
    };
    let Some(id) = object.get("id") else {
        // A notification is never answered, not even when it is malformed.
        return None;
    };
    if !(id.is_string() || id.is_number() || id.is_null()) {
        return Some(error(&Value::Null, -32600, "the id must be a string or a number"));
    }
    if object.get("jsonrpc").and_then(Value::as_str) != Some("2.0") {
        return Some(error(id, -32600, "jsonrpc must be \"2.0\""));
    }
    let Some(method) = object.get("method").and_then(Value::as_str) else {
        // A response to a request of ours: there are none.
        if object.contains_key("result") || object.contains_key("error") {
            return None;
        }
        return Some(error(id, -32600, "a request needs a method"));
    };
    let params = object.get("params");
    let reply = |result: Value| json!({"jsonrpc": "2.0", "id": id, "result": result});
    Some(match method {
        "initialize" => {
            let asked = params.and_then(|p| p.get("protocolVersion")).and_then(Value::as_str).unwrap_or_default();
            let version = VERSIONS.iter().find(|v| **v == asked).copied().unwrap_or(VERSIONS[0]);
            reply(json!({"protocolVersion": version, "capabilities": {"tools": {}},
                "serverInfo": {"name": "zerus", "version": env!("CARGO_PKG_VERSION")}, "instructions": INSTRUCTIONS}))
        }
        "ping" => reply(json!({})),
        "tools/list" => reply(json!({"tools": tools()})),
        "tools/call" => {
            let Some(params) = params.and_then(Value::as_object) else {
                return Some(error(id, -32602, "tools/call needs params with a tool name"));
            };
            let Some(name) = params.get("name").and_then(Value::as_str) else {
                return Some(error(id, -32602, "tools/call needs a tool name"));
            };
            if !tools().as_array().is_some_and(|all| all.iter().any(|t| t["name"] == name)) {
                return Some(error(id, -32602, &format!("unknown tool {name}")));
            }
            let arguments = match params.get("arguments") {
                None | Some(Value::Null) => json!({}),
                Some(v) if v.is_object() => v.clone(),
                Some(_) => return Some(error(id, -32602, "arguments must be an object")),
            };
            reply(tool_result(call(name, &arguments)))
        }
        _ => error(id, -32601, &format!("method not found: {method}")),
    })
}

fn serve(call: &dyn Fn(&str, &Value) -> Result<String>, mut input: impl BufRead, mut output: impl Write) -> std::io::Result<()> {
    let mut line = Vec::new();
    loop {
        line.clear();
        let read = std::io::Read::take(&mut input, MAX_LINE + 1).read_until(b'\n', &mut line)?;
        if read == 0 {
            return Ok(());
        }
        let mut answer = None;
        if !line.ends_with(b"\n") && line.len() as u64 > MAX_LINE {
            // Too long: skip the rest of the line and say so.
            loop {
                let (skip, done) = {
                    let buffer = input.fill_buf()?;
                    match buffer.iter().position(|b| *b == b'\n') {
                        Some(at) => (at + 1, true),
                        None => (buffer.len(), buffer.is_empty()),
                    }
                };
                input.consume(skip);
                if done {
                    break;
                }
            }
            answer = Some(error(&Value::Null, -32600, "the message exceeds 1 MiB"));
        } else if !line.iter().all(u8::is_ascii_whitespace) {
            answer = match serde_json::from_slice::<Value>(&line) {
                Ok(message) => handle(call, &message),
                Err(e) => {
                    eprintln!("hgs mcp: unparsable message: {e}");
                    Some(error(&Value::Null, -32700, "parse error"))
                }
            };
        }
        if let Some(answer) = answer {
            writeln!(output, "{answer}")?;
            output.flush()?;
        }
    }
}

pub fn dispatch(config: &Config, args: &[String], dry: bool) -> Result<i32> {
    if dry || !args.is_empty() {
        return Err(fail("usage: hgs mcp (Zerus attaches it to the agent sessions it starts)"));
    }
    let call = |name: &str, arguments: &Value| -> Result<String> { tool(config, &caller(config)?, name, arguments) };
    serve(&call, std::io::stdin().lock(), std::io::stdout().lock()).map_err(fail)?;
    Ok(0)
}
```

```rust
/// The agents Zerus starts with the task tools; the others use `hgs task`.
pub(crate) fn serves(agent: &str) -> bool {
    matches!(agent, "claude" | "codex")
}

/// What Codex passes on to the server from the agent's environment, which it
/// otherwise clears: the session the server verifies and what hgs reads to find
/// its state and configuration, the tmux server of the sessions it pastes into
/// and the SSH access to other computers. Absent names are skipped.
const SERVER_ENV: [&str; 22] = [
    "HOME", "PATH", "USER", "LANG", "HGS_SESSION", "HGS_RUN_ID", "HGS_STATE_DIR", "HGS_CONFIG_DIR",
    "HGS_EXECUTABLE", "HGS_SELF", "HGS_PEERS", "HGS_SSH", "XDG_STATE_HOME", "XDG_RUNTIME_DIR",
    "SSH_AUTH_SOCK", "TMUX", "TMUX_TMPDIR", "USERPROFILE", "APPDATA", "LOCALAPPDATA", "COMPUTERNAME", "PATHEXT",
];

/// How long Codex waits for one tool: a start for another computer's session
/// first brings both copies of the project up to date.
const CODEX_TOOL_TIMEOUT: u64 = 120;

/// `argv` with the MCP server `zerus` and the permission to call its tools,
/// before its `--`, if any. Only the spawned command gets them: the saved
/// command stays as launched, so every start attaches them again. Claude's
/// `--mcp-config` takes several values, so it comes last.
pub(crate) fn attach(agent: &str, executable: &str, argv: &mut Vec<String>) {
    if argv.is_empty() || !serves(agent) {
        return;
    }
    let at = argv.iter().position(|arg| arg == "--").unwrap_or(argv.len());
    let flags: Vec<String> = if agent == "claude" {
        let server = json!({"type": "stdio", "command": executable, "args": ["mcp"]});
        vec!["--allowedTools".into(), "mcp__zerus".into(), "--mcp-config".into(), json!({"mcpServers": {"zerus": server}}).to_string()]
    } else {
        // Codex reads each override value as TOML.
        let list = |items: &[&str]| toml_edit::Value::Array(items.iter().copied().collect()).to_string();
        [
            ("command", toml_edit::Value::from(executable).to_string()),
            ("args", list(&["mcp"])),
            ("env_vars", list(&SERVER_ENV)),
            ("default_tools_approval_mode", toml_edit::Value::from("approve").to_string()),
            ("tool_timeout_sec", CODEX_TOOL_TIMEOUT.to_string()),
        ]
        .into_iter()
        .flat_map(|(key, value)| ["-c".to_owned(), format!("mcp_servers.zerus.{key}={value}")])
        .collect()
    };
    argv.splice(at..at, flags);
}
```

```python
def offered(tools):
    """Tool names, including those inside namespaces."""
    return {name for tool in tools if isinstance(tool, dict)
            for name in (offered(tool.get('tools') or []) if tool.get('type') == 'namespace' else [tool.get('name')])}


class Attached(test_fork.Base):
    """The flags hgs gives a fake agent of the same name, with the server
    command replaced by the stub."""

    def flags(self, agent):
        self.start(agent, 'native')
        argv = json.loads((self.root / 'argv.jsonl').read_text().splitlines()[-1])['argv']
        stub = self.root / 'zerus-stub'
        stub.write_text(STUB % str(self.root / 'stub.log'))
        stub.chmod(0o755)
        if agent == 'claude':
            # The flags exactly as hgs gave them; only the server command changes.
            at = argv.index('--mcp-config')
            start = at - 2 if argv[at - 2:at] == ['--allowedTools', 'mcp__zerus'] else at
            config = json.loads(argv[at + 1])
            config['mcpServers']['zerus']['command'] = str(stub)
            return argv[start:at + 1] + [json.dumps(config)]
        flags = []
        for i, word in enumerate(argv):
            if word == '-c' and argv[i + 1].startswith('mcp_servers.zerus.'):
                value = argv[i + 1]
                if value.startswith('mcp_servers.zerus.command='):
                    value = 'mcp_servers.zerus.command=' + json.dumps(str(stub))
                flags += ['-c', value]
        return flags

    def stub_log(self):
        path = self.root / 'stub.log'
        return path.read_text().splitlines() if path.exists() else []

    def assert_served(self, session):
        lines = self.stub_log()
        self.assertTrue(lines, 'the agent never started the server')
        started = json.loads(lines[0])
        self.assertEqual(started['argv'], ['mcp'])
        self.assertEqual({k: started['env'].get(k) for k in session}, session)
        self.assertTrue(any('"tools/call"' in line for line in lines[1:]), 'the agent never called the tool\n' + '\n'.join(lines))

    def test_codex_starts_the_server_with_the_session_and_calls_it_without_asking(self):
        flags = self.flags('codex')
        requests = []

        class Provider(http.server.BaseHTTPRequestHandler):
            def log_message(self, *args):
                pass

            def do_POST(self):
                body = json.loads(self.rfile.read(int(self.headers.get('Content-Length', 0))) or b'{}')
                requests.append(body)
                items = [i for i in body.get('input') or [] if isinstance(i, dict)]
                tools = offered((body.get('tools') or []) + [t for i in items if i.get('type') == 'additional_tools' for t in i.get('tools') or []])
                answered = any(i.get('type') in ('function_call_output', 'custom_tool_call_output') for i in items)
                direct = next((name for name in tools if name and name.endswith('task_list')), None)
                if answered:
                    item = dict(type='message', id='msg_1', role='assistant', status='completed',
                                content=[dict(type='output_text', text='Fixture complete.', annotations=[])])
                elif direct:
                    item = dict(type='function_call', id='fc_1', call_id='call_1', name=direct, arguments='{}', status='completed')
                else:
                    # Codex 0.159-0.162 reach MCP tools through code mode.
                    item = dict(type='custom_tool_call', id='ctc_1', call_id='call_1', name='exec', status='completed',
                                input='const r = await tools.mcp__zerus__task_list({});\ntext(JSON.stringify(r));')
                response = dict(id='resp_1', object='response', status='completed', output=[item],
                                usage=dict(input_tokens=1, output_tokens=1, total_tokens=2))
                self.send_response(200)
                self.send_header('Content-Type', 'text/event-stream')
                self.end_headers()
                for kind, value in [('response.created', dict(response=dict(response, status='in_progress', output=[]))),
                                    ('response.output_item.added', dict(output_index=0, item=item)),
                                    ('response.output_item.done', dict(output_index=0, item=item)),
                                    ('response.completed', dict(response=response))]:
                    self.wfile.write(('event: ' + kind + '\ndata: ' + json.dumps(dict(type=kind, **value)) + '\n\n').encode())
                    self.wfile.flush()

        server = http.server.ThreadingHTTPServer(('127.0.0.1', 0), Provider)
        self.addCleanup(server.server_close)
        self.addCleanup(server.shutdown)
        threading.Thread(target=server.serve_forever, daemon=True).start()
        home = self.root / 'native-codex'
        home.mkdir()
        (home / 'config.toml').write_text('model="gpt-6.1-sol"\nmodel_provider="fixture"\ncheck_for_update_on_startup=false\n'
                                          '[model_providers.fixture]\nname="Fixture"\nbase_url="http://127.0.0.1:' + str(server.server_port) + '/v1"\n'
                                          'wire_api="responses"\nrequest_max_retries=0\nstream_max_retries=0\n')
        # Most forwarded variables are absent here; the server starts all the same.
        session = dict(HGS_SESSION='codex/orchard/api', HGS_RUN_ID='run-native', HGS_STATE_DIR=str(self.root / 'state'))
        env = dict(HOME=str(self.root), PATH=os.environ['PATH'], CODEX_HOME=str(home), OPENAI_API_KEY='fixture', **session)

        self.assertEqual(run.returncode, 0, run.stdout + run.stderr)
        self.assert_served(session)
        outputs = [i for i in requests[-1].get('input', []) if i.get('type') in ('function_call_output', 'custom_tool_call_output')]
        self.assertIn('STUB-TASKS', json.dumps(outputs))
        self.assertNotIn('requires approval', json.dumps(outputs))


@unittest.skipUnless(os.environ.get('HGS_CLAUDE_TEST_BIN'), 'Set HGS_CLAUDE_TEST_BIN for the isolated native Claude task tools test')
class NativeClaudeTaskTools(Attached):
    def test_claude_starts_the_server_with_the_session_and_calls_it_without_asking(self):
        flags = self.flags('claude')
        requests = []

        class Api(http.server.BaseHTTPRequestHandler):
            def log_message(self, *args):
                pass

            def do_POST(self):
                body = json.loads(self.rfile.read(int(self.headers.get('Content-Length', 0))) or b'{}')
                if not self.path.startswith('/v1/messages') or 'count_tokens' in self.path:
                    self.send_response(200)
                    self.send_header('Content-Type', 'application/json')
                    self.end_headers()
                    self.wfile.write(b'{"input_tokens":1}')
                    return
                requests.append(body)
                answered = any(isinstance(m.get('content'), list) and any(b.get('type') == 'tool_result' for b in m['content'])
                               for m in body.get('messages', []))
                offers = 'mcp__zerus__task_list' in offered(body.get('tools', []))
                blocks = ([dict(type='tool_use', id='toolu_1', name='mcp__zerus__task_list', input={})] if offers and not answered
                          else [dict(type='text', text='Fixture complete.')])
                tool = blocks[0]['type'] == 'tool_use'
                message = dict(id='msg_1', type='message', role='assistant', model=body.get('model', 'claude-sonnet-4-6'),
                               content=blocks, stop_reason='tool_use' if tool else 'end_turn', stop_sequence=None,
                               usage=dict(input_tokens=1, output_tokens=1))
                self.send_response(200)
                self.send_header('Content-Type', 'text/event-stream')
                self.end_headers()

                def emit(kind, **data):
                    self.wfile.write(('event: ' + kind + '\ndata: ' + json.dumps(dict(type=kind, **data)) + '\n\n').encode())
                    self.wfile.flush()
                emit('message_start', message=dict(message, content=[], stop_reason=None))
                for i, b in enumerate(blocks):
                    emit('content_block_start', index=i, content_block=dict(b, input={}) if b['type'] == 'tool_use' else dict(b, text=''))
                    emit('content_block_delta', index=i, delta=dict(type='input_json_delta', partial_json=json.dumps(b['input']))
                         if b['type'] == 'tool_use' else dict(type='text_delta', text=b['text']))
                    emit('content_block_stop', index=i)
                emit('message_delta', delta=dict(stop_reason=message['stop_reason'], stop_sequence=None), usage=dict(output_tokens=1))
                emit('message_stop')

        server = http.server.ThreadingHTTPServer(('127.0.0.1', 0), Api)
        self.addCleanup(server.server_close)
        self.addCleanup(server.shutdown)
        threading.Thread(target=server.serve_forever, daemon=True).start()
        home = self.root / 'native-claude'
        home.mkdir()
        (home / '.claude.json').write_text(json.dumps(dict(hasCompletedOnboarding=True,
                                                           customApiKeyResponses=dict(approved=['fixture-key'], rejected=[]))))
        session = dict(HGS_SESSION='claude/orchard/api', HGS_RUN_ID='run-native', HGS_STATE_DIR=str(self.root / 'state'))
        # The default permission mode: only the allowed tools run without asking.
        env = dict(HOME=str(home), PATH=os.environ['PATH'], CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC='1',
                   ANTHROPIC_API_KEY='fixture-key', ANTHROPIC_BASE_URL='http://127.0.0.1:' + str(server.server_port), **session)
        run = subprocess.run([os.environ['HGS_CLAUDE_TEST_BIN'], '-p', 'List the tasks.', '--model', 'claude-sonnet-4-6', *flags],
                             env=env, stdin=subprocess.DEVNULL, capture_output=True, text=True, timeout=120)
        self.assertEqual(run.returncode, 0, run.stdout + run.stderr)
        self.assert_served(session)
        results = [b for r in requests for m in r.get('messages', []) if isinstance(m.get('content'), list)
                   for b in m['content'] if b.get('type') == 'tool_result']
        self.assertIn('STUB-TASKS', json.dumps(results))
        self.assertNotIn('requested permissions', json.dumps(results))
```

```markdown
### Task tools for agents

Zerus starts Claude Code and Codex sessions with the MCP server `zerus`
(`hgs mcp`), on the command line of that start only: Claude Code gets
`--mcp-config` and `--allowedTools mcp__zerus`, Codex gets
`-c mcp_servers.zerus.…` overrides that pass `HGS_SESSION`, `HGS_RUN_ID` and the
variables hgs reads on to the server and approve its tools. The agent's own
configuration and saved resume commands never contain it, and the run record
says `"zerus_mcp": true`.

The server acts as the session that runs it. Every call checks that this run of
the session is live on this computer and that it belongs to a catalog project;
otherwise every tool refuses with the reason. Its tools (`task_add`,
`task_move`, `task_edit`, `task_stage`, `task_target`, `task_cancel`,
`task_start`, `task_list`, `task_get`, `task_comment`, `task_report`) run the
`hgs task` command they equal, on that project, and answer with what happened;
`task_start` and `task_cancel` for a session on another computer run there as
`hgs task send` and `cancel` do. Task prompts name the tools (`zerus.task_report`)
for a session whose current run has the server, and the `hgs task` commands for
one started by an older Zerus, until its next resume.
```
