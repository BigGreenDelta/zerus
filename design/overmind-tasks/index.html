Overmind Tasks: четыре направления

Одни и те же задачи проекта Alpha в окне Zerus. Кликните сессию слева, чтобы сменить выбранную: её задачи отмечены зелёной полосой. Кликайте задачи, сворачивайте группы, перетаскивайте задачи между стадиями (в «G» — на другую сессию или в пул проекта), фильтруйте. Ширина окна меняет место под задачами: у окна 1100 px остаётся около 680 px.

Готово.

Сейчас

Отдельная вкладка: колонки по 244 px, карточка поверх доски.

  • В 1280 px видно две-три колонки, дальше горизонтальная прокрутка.

D · Боковая панель

Вкладки Tasks нет. Справа от Activity узкая панель 300 px: Your Call, задачи этой сессии, затем задачи проекта по стадиям одной строкой. Карточка открывается внутри панели, внизу поле добавления задачи.

  • Задачи всегда рядом с разговором, не нужно переключать вкладку.
  • Ширина постоянная и небольшая.
  • Activity уже на 310 px; панель можно было бы скрывать кнопкой.

E · Таблица

Одна строка на задачу, стадия — значение в столбце (меняется прямо в ячейке). Группировка по стадии, сессии или без неё; сортировка по клику на заголовок.

  • Самая плотная форма: 25+ задач на экране.
  • На узком окне прячутся метки, потом сессия.
  • Похоже на трекер, а не на доску.

F · Стадии строками

Канбан, повёрнутый на 90°: стадия — горизонтальная дорожка, задачи — плашки, которые переносятся по ширине. Перетаскивание между дорожками.

  • Видна вся доска без горизонтальной прокрутки при любой ширине.
  • Заголовки обрезаются до ширины плашки (до 250 px).

G · В списке сессий

Отдельной доски нет. Задачи висят под своими сессиями в левом списке, пул проекта — строкой под проектом. Клик по задаче открывает её карточку на месте Activity.

  • Ноль дополнительной ширины; видно, кто чем занят.
  • Перетащите задачу на другую сессию, чтобы отдать её.
  • Список сессий длиннее; обзор всех стадий проекта — только через пул.
