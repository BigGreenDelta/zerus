Сейчас

Колонки по 244 px, карточка накрывает доску справа.

  • В окно 1280 px помещаются две-три колонки, остальное — горизонтальная прокрутка.
  • Открытая карточка закрывает ещё половину доски.

A · Список по стадиям

Одна колонка: секция на стадию, задача — строка высотой 32 px. Карточка встаёт справа, список сужается.

  • Ширина нужна только под заголовок; на узком окне прячутся метки, потом сессия.
  • Видно 15–20 задач без прокрутки; Done и Icebox свёрнуты.
  • Нет картины потока «слева направо», как у канбана.

B · Компактный канбан

Колонки делят доступную ширину (118–280 px), пустые стадии и Done/Icebox — полоски по 30 px. Карточка — выезжающая панель поверх доски.

  • Остаётся канбан: поток и перетаскивание между колонками.
  • Пять рабочих стадий помещаются в 680 px без прокрутки.
  • Узкие колонки: заголовок в две строки, метки обрезаются.

C · Конвейер + список

Сверху конвейер стадий со счётчиками, под ним список выбранной стадии (или всех активных). Карточка закреплена справа.

  • Одна строка на весь workflow; счётчики видны всегда.
  • Строка задачи в две линии: полный заголовок, метки и сессия.
  • Задачи разных стадий видны вместе только в режиме «All active».
